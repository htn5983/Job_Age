## 📌 專案簡介

**Taichung Job Age** 是一個以「臺中市求職年齡分布」為主題的資料分析與資料視覺化專案。

本專案透過 **臺中市政府公開資料 API**，取得臺中市就業服務相關的月資料，將不同年齡層與性別的「新登記求職人數」進行整理、儲存與視覺化。

希望透過簡潔的資料視覺化方式，讓使用者能快速了解：

- 👥 不同年齡層的求職人數
- 👨 男性與女性求職者的差異
- 📈 哪些年齡層是主要求職族群
- 🔎 各年齡欄位的詳細資料
- 📅 最新月份的求職資料狀況

本專案不只是單純製作一個網頁，而是將 **資料取得 → 資料整理 → 資料庫儲存 → 資料分析 → 網頁視覺化** 串接成一個完整的小型資料專案。

---

# 🎯 專案目的

本專案主要有以下幾個目的：

### 1. 觀察臺中市求職年齡分布

分析不同年齡層的新登記求職人數，了解目前臺中市主要求職人口集中在哪些年齡區間。

### 2. 比較男女求職人口

將男性與女性求職人數進行並列比較，觀察不同年齡層的性別差異。

### 3. 建立資料處理流程

透過 Python 取得政府公開資料 API，進行資料整理後寫入資料庫，建立可重複執行的資料更新流程。

### 4. 將資料轉換成容易理解的資訊

透過網頁介面與視覺化設計，把原本較難閱讀的資料轉換成使用者容易理解的圖表與統計資訊。
